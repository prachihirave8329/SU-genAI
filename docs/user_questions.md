
# JanAushadhiFinder - Real User Questions

## Core questions from the project card

Q1. What is JanAushadhiFinder?

Q2. Where can I find a nearby Jan Aushadhi Kendra?

Q3. Where can I check medicine information?

Q4. What is the price of Paracetamol 500 mg?

Q5. What is the strength and unit size of Paracetamol?

Q6. Is Paracetamol 500 mg currently available in stock
at my nearest Jan Aushadhi Kendra?

## Additional realistic user questions

Q7. What is the drug code of Paracetamol?

Q8. Which medicines belong to the Painkiller therapeutic group?

Q9. How much does a particular generic medicine cost?

Q10. Can I search for a medicine using its generic name?

## Dataset limitations

Q6 cannot be answered using the current dataset because
the application does not have real-time Kendra stock data.

The current medicine records contain:
- Drug code
- Generic name
- Strength
- Unit size
- MRP in INR
- Therapeutic group

The dataset does not contain live stock information
or real-time Kendra inventory.

The application must clearly tell users when information
is unavailable instead of making up an answer.
